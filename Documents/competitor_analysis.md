# Competitor Analysis

## Unique Value Proposition
Our Project, aims to solve the difficulties students encounter when choosing courses for first year students and those in elective heavy degrees. We believe that our unique value proposition is the combination of: 1. a course comparison tool for electives, filtering for workload, difficulty, assessments and relevance. 2. a centralised repository of easy to read course summaries that shows prerequisites, assessment structure and workload. And 3. A guided course-planning tool that helps students map out degree requirements and semester-by-semester choices. The following competitor analysis includes a comparison table, SWOT analysis of key competitors and strategic insights based on these findings.

## SWOT Analysis
***Programs and Courses Database:***

**Strengths:** Large amount of info. External links to useful resources.

**Weaknesses:** Difficulty with navigation, finding what users need. Information not presented intuitively. Overreliance on external sources.

**Opportunities:** Students want a lot of different types of information when choosing courses. 

**Threats:** A greater centralisation of information and easier naviagation of course repositories.

***UQ Pre-prepared Study Plans:***

**Strengths:** Easy to follow, simple structure, guaranteed prerequisites and graduation.

**Weaknesses:** Rigid, difficult to personalise. Electives not given priority.

**Opportunities:** Students like structured visually appealing guides for course planning.

**Threats:** 'One size fits all' approach vulnerable to more customisable tools which can accomodate electives.

| Insight | Strategic Implication |
| ------- | --------------------- |
| Most competitors focus on information or planning, not both | Can we provide students with the information they want and need while also giving them planning tools? |
| Competitor tools are either rigid and built for purpose or customisable but need to be adapted to customer needs. | Can we create a planning tool which is both tailor-made for UQ students but also allows them to customise and modify based on their needs? |
| Even the best competitors rely on external sources. | Can we centralise a lot of course information rather than directing users to other sites? |
| Navigation of course repositories is difficult whe not specifically looking for one course. | Can we create search features for courses which offer students an easier experience?
