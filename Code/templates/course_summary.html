Course Description

This course provides a comprehensive introduction to the design and analysis of algorithms and data structures. It covers fundamental techniques such as divide-and-conquer, dynamic programming, and greedy algorithms, applying them to classic problems in sorting, graph theory, and combinatorial optimization.

Students will learn to rigorously analyze the time and space complexity of their solutions using Big-O notation, and will gain practical experience implementing complex structures like Red-Black Trees, Heaps, and Hash Tables in C++ or Java.
